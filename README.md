# ShopNest — E-Commerce Website

A responsive e-commerce website where users can explore products, view product details, and manage their cart and wishlist.

**Demo:** https://shop-nest-vert.vercel.app/

**GitHub:** https://github.com/soniyachaudhary0703-code/ShopNest

## Features

- Browse products and view product details
- Add and remove products from the cart
- Add and remove products from the wishlist
- User login and registration interface
- Cart and wishlist data stored in LocalStorage
- Responsive user interface
- Easy navigation between pages

## Technologies Used

**Frontend:** React, JavaScript, Tailwind CSS, React Router, React Icons

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT

**Deployment:** Vercel

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/soniyachaudhary0703-code/ShopNest.git
   ```

2. Open the project folder:

   ```bash
   cd ShopNest
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the frontend:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

**Backend setup:** Configure the backend environment variables in `backend/.env`, connect MongoDB, and start the backend separately.
