ShopNest — E-commerce App
A responsive e-commerce website with product browsing, product details, cart, wishlist, and user authentication.
Live Demo
https://shop-nest-vert.vercel.app/
Features
- Browse products and view details
- Add items to cart and wishlist
- Login and register
- Cart and wishlist saved in localStorage
Tech Stack
React, JavaScript, Tailwind CSS, React Router, Node.js, Express.js, MongoDB, Mongoose, JWT, Vercel
Login Details
A demo account is not pre-created. If the backend is running, first register with these details, then use the same details to log in:
- Email: demo@shopnest.com
- Password: ShopNest@123
These credentials will work only after you create the account through Register. The live demo's login/register may not work until the backend is deployed and its API URL is configured.
Run Locally
git clone https://github.com/soniyachaudhary0703-code/ShopNest.git
cd ShopNest
npm install
npm run dev
For backend setup, configure backend/.env, install dependencies in backend, then run node Server.js.
